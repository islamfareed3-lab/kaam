# kaamSet

Domestic and household hiring marketplace for Pakistan.

Workers create accounts with a phone number and upload profiles. Households and companies (restaurants, offices, hotels, and more) browse, post paid job ads, and hire. English and Urdu are chosen at signup.

## Product model

- **8% commission** on successful hires (charged to the hirer)
- **Verified profiles**, **featured listings**, **job advertisements**
- Business plans, urgent alerts, background-check assist, contract packs
- Workers are **not** charged placement fees

## Stack

- Next.js App Router · TypeScript · Tailwind CSS
- Demo auth/data stored in browser `localStorage` (OTP demo code: `123456`)

## Local development

```bash
npm install
npm run dev
```

## Legal note

Terms, privacy, and worker-rights pages are MVP drafts for Pakistan domestic hiring norms. Have a Pakistan-qualified lawyer review before commercial launch.
